Build the version your child needs

Sorting is useful across many subjects. Change the categories and cards for phonics, animals, recycling, food, music, geography—or this week’s latest interest.

Build me a polished, mobile-friendly sorting game as one standalone HTML file. Let a parent create and delete custom category names, then add cards with an emoji, short label and correct category. During play, show one shuffled card at a time with large category buttons, immediate feedback, score and streak. Save the custom game locally in the browser, include an editable starter set, accessible controls, an accurate privacy note and no external services.
Privacy: Categories and cards stay in this browser’s local storage. The current score and streak last only for that game. The app has no account, analytics, advertising or external service. Clearing browser data removes the saved game.

Grown-up note: A parent or carer creates and checks the categories and answers for accuracy and suitability.
