Copy this beginner-friendly prompt into an AI coding tool:

Build me one mobile-friendly HTML file for a colour-code logic game. Let me choose a player name and difficulty, make a random hidden colour pattern, score every guess with exact-position and wrong-position clues, offer a one-slot hint, and save wins and best score in local browser storage. Use no external libraries. Explain privacy clearly and include large accessible buttons.
How the clues work

Dark dot: one colour is correct and in the correct slot. Ring: one colour is in the code but belongs in another slot. Each colour can appear once in this version. The order of clue dots does not identify particular slots.
