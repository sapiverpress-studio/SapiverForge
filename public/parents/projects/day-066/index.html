Privacy, learning and grown-up controls

Messages, player names, settings and recent scores are saved only in local storage in this browser profile. Nothing is uploaded and no account, camera, microphone or external service is used. Anyone using the same browser profile may be able to see the saved messages.

A grown-up creates or checks every message and hint for accuracy and suitability. This is a playful symbol-substitution game rather than secure encryption: never use it to store passwords, personal information or real secrets.
