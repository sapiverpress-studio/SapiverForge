How it works

Digital screens make colours by adding red, green and blue light. Each slider runs from 0 to 255. The challenge score compares those three values; it is a playful estimate, not a scientific colour measurement. Screens and brightness settings can look different.

Privacy

This app runs entirely in your browser. Custom targets, saved palette colours and best scores are stored only in this browser's local storage. Nothing is uploaded. There is no account, advertising, camera, microphone, location access or external service. Anyone using the same browser profile may see the saved data, and clearing browser data removes it.
