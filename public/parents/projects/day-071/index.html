Privacy

This app runs entirely in this browser. The current animation, palette, speed and up to six named projects stay in local browser storage on this device. Nothing is uploaded. There is no account, advertising, camera, microphone or external service.

Downloaded PNG files are managed through your device’s normal files and sharing controls.

Grown-up note

A grown-up should check project names and pictures before saving, downloading or sharing them. Local browser storage is not a permanent backup, and clearing site data removes saved projects.

Copy this beginner-friendly prompt and change the details for your family:

Create one mobile-friendly HTML file for a private frame-by-frame pixel animation studio. Include an 8×8, 12×12 or 16×16 drawing canvas, pencil, eraser, colour picker, palette and optional onion-skin view of the previous frame. Let users add, duplicate, select and delete up to 12 frames, preview the loop at 1–12 frames per second, save up to six named projects in localStorage, and download the current frame or a horizontal transparent PNG sprite sheet. Use no external libraries, accounts, analytics or paid services. Include accessible labels, accurate privacy wording and a grown-up sharing note.
