#### **[5] Anthropic Replaces Git with In-House "Scion" Version Control**
* **What is confirmed:** Anthropic published an engineering post revealing it migrated its main monorepo from Git to a custom internal version control system called "Scion". The move was driven by daily code merges surging from ~2,500 in May to over 30,000 per day in September 2026, largely due to autonomous Claude coding agents overwhelming standard Git infrastructure.
* **Important caveats:** Scion was designed specifically for Anthropic’s centralized, online monorepo architecture and agent workflows; Anthropic confirmed it has no plans to open-source Scion as a general Git replacement.
* **Publication suitability:** **Yes.** Excellent technical depth illustrating how AI agent adoption is breaking traditional developer infrastructure.
