How it works

Each maze is built in the browser using a depth-first maze-generation algorithm. It carves a connected path through every cell, so the goal is always reachable. The hint follows a calculated route from your current square.

Privacy

This app runs entirely in your browser. Your character, goal, colours and best runs stay in local browser storage on this device. Nothing is uploaded. There is no account, advertising, camera, microphone, location, analytics or external service. Anyone using the same browser profile may see the saved settings, and clearing browser data removes them.
