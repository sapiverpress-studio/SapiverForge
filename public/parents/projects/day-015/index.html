You do not need to find a generic memory game. Ask AI to build the version that matches your child’s interests, current schoolwork and preferred style.

Build me a polished, mobile-friendly memory matching game as one standalone HTML file. Let a parent create and delete custom pairs using an emoji and a short word. Shuffle the cards, count moves, show matched pairs, celebrate completion and save the custom deck and best score in local browser storage. Include an editable starter deck, accessible buttons, a privacy explanation and no external services.
Privacy: Your deck and best score stay in this browser’s local storage. This app has no account, analytics, advertising or external service. Clearing browser data removes the saved information.

Grown-up note: A parent or carer should choose suitable words and pictures and decide how the game is used.
