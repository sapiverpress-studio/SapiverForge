Privacy

This app runs entirely in this browser. The typist name, practice lines, settings and recent results are saved in local browser storage on this device. Nothing is uploaded. There is no account, advertising, camera, microphone or external service.

Anyone using the same browser profile may be able to see the saved information. Clearing site data removes it.

Grown-up note

A grown-up creates or checks every practice line and chooses a comfortable session length. Speed and accuracy are informal practice estimates, not an assessment. Avoid comparing children, and stop if hands feel uncomfortable.
