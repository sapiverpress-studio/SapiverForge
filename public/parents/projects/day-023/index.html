Private by design

This app runs entirely in this browser. Item names, people or places, dates, notes and return history are stored only in local browser storage on this device. Nothing is uploaded. Clearing browser data removes the list.

For grown-ups

Use simple labels rather than sensitive personal information. The board does not send reminders or contact anyone, so a grown-up still checks real return arrangements and dates.

Build your own with AI

Build me a mobile-friendly family borrowing tracker as one standalone HTML file. Let me record whether we lent or borrowed an item, its name, the person or place, the date, an optional return date and notes. Automatically show overdue and due-soon items, provide open, lent, borrowed and returned filters, search, edit, mark returned, reopen, delete and print controls, and save everything locally in the browser. Do not use external libraries or send data anywhere.
