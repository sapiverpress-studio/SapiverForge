Privacy

This app runs entirely in this browser. Player names, settings and the last 20 rally results are stored in local browser storage on this device. Nothing is uploaded. There is no account, advertising, camera, microphone, motion sensor or external service.

Anyone using the same browser profile may be able to see the saved names and scores. Clearing site data removes them.

Grown-up note

This is a playful screen estimate, not a medical, developmental or sporting assessment. Device, browser, screen and input delay affect every score. Compare a player only with their own results, use short sessions and stop if tapping is uncomfortable.

Build your own with AI

Copy this beginner-friendly prompt and change the details for your family:

Create one mobile-friendly HTML file for a private family reaction-time game. Let a parent add player names, choose 5 or 8 rounds and select colour, symbol or mixed cues. After a random 1.5–4 second wait, show a clear cue and measure the time until a tap, click, Enter or Space. Detect false starts, calculate the median, best time and score spread, and save only the last 20 results in localStorage. Include accessible labels, reduced-motion support, accurate privacy wording, a grown-up note explaining that results are informal device-dependent estimates, and no external libraries, accounts, analytics or paid services.
